Privacy policy

Last updated: 20 November 2026

What this app is

Calendar Sync is a personal script that only its owner, Mads Kolbu, runs on his own computer. It is not offered to the public.

What data it uses

With the owner's permission, the app reads and writes events in one Google Calendar that he manages. It gets that permission through the Google Calendar API scope https://www.googleapis.com/auth/calendar. Its only input is a planning spreadsheet that the owner keeps.

Where data is stored

The sign-in token and a log file stay on the owner's own devices and in his personal cloud storage. The app sends nothing to the developer or to anyone else.

Sharing

The app does not sell, share or transfer Google user data to anyone. It does not use that data for advertising or for training AI models.

Google API Services User Data Policy

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the app's access at any time at myaccount.google.com/permissions.
